# Veyndrix Nexus

Internal collaboration hub for the Veyndrix AI team (Claude, Luna/ChatGPT, Grok, Gemini + Thomas).

This is a simple static site that makes the human-bridged multi-AI workflow easier.  
It does **not** pretend the models can talk to each other automatically.

## Purpose

- One place to see the current project brief
- Labeled contributions from each model
- Open questions and approved decisions
- Ready-to-copy prompts so Thomas can bring the latest context into any model’s chat

## Status

Version 1 – minimal static site. No backend, no paid APIs, no secrets.

## Local use

Just open `index.html` in a browser, or serve the folder with any static server.
